# Creeyto Studios website

A static multipage website for Creeyto Studios.

## Pages

- `index.html` — Home
- `studio.html` — Studio
- `services.html` — Services overview
- `web-design.html` — Web design and development
- `digital-marketing.html` — Digital marketing
- `graphic-design.html` — Brand and graphic design
- `contact.html` — Project enquiry form

## Preview

Open `index.html` in a browser, or serve this folder with any static web server.

The enquiry form sends submissions to `hello@creeyto.com` through FormSubmit's AJAX endpoint. The inbox must complete FormSubmit's one-time activation before submissions are forwarded.
